# 自己紹介システム リメイク設計書 概要

## 1. 目的

現行の自己紹介ページ（GitHub Pages上で静的HTML＋JSON＋GitHub Actionsにより運営）を、Djangoによる動的なWebシステムとしてリメイクする。内容の更新を、リポジトリへのファイル編集・コミット・デプロイではなく、管理画面上の操作で完結できるようにすることが目的。

## 2. リメイク元

- 旧リポジトリ：https://github.com/Ma2naga190330/introduction
- 構成：`index.html`（表示） + `data/profile.json`（データ） + `css/style.css` + `js/main.js`（JSONをフロントエンドで描画）
- 掲載内容：プロフィールヘッダー（氏名・学校情報・SNSリンク・アバター）、活動・実績、保有資格・検定、スキル

## 3. 今回のシステムのスコープ

- **実装方式**：Django（MVT）。REST APIは作らない。画面（テンプレート）とビュー（関数ベース）、フォームで完結させる。
- **対象データ**：活動実績・資格情報・スキルの3種類をDB化し、管理者が管理画面から登録・編集・削除できるようにする。
- **対象外**：プロフィールヘッダー部（氏名・学校情報・SNSリンク・アバター画像）は今回の管理対象に含めない。テンプレートの固定値として扱う。
- **管理者**：システム全体でプロフィール所有者1名のみを想定する（複数管理者・権限分けは扱わない）。Django標準の`User`モデルを認証に利用する。
- **タグ**：活動実績に付与するタグ（例：Winner、organizer）は独立したデータとして持つが、専用の管理画面は用意しない。活動実績の登録・編集フォーム内で入力し、その場で取得または新規作成する。

## 4. アクター

| アクター | 説明 |
| --- | --- |
| 訪問者 | プロフィールページを閲覧する一般の来訪者 |
| 管理者 | ログインして活動実績・資格・スキルを編集する、プロフィール所有者本人 |
